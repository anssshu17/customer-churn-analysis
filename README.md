# Customer Churn Analysis

## Project Overview
This project analyzes customer churn behavior using Python, SQL, and Power BI to identify factors affecting customer retention.

## Objective
The goal of this project is to identify key reasons behind customer churn and provide business insights to improve customer retention.

## Tools & Technologies Used
- Python (Pandas, NumPy)
- SQL Server
- Power BI
- Excel

## Project Workflow
1. Data Cleaning using Python
2. Exploratory Data Analysis (EDA)
3. SQL-based churn analysis
4. Dashboard creation in Power BI
5. Business insight generation

## Key Insights
- Customers with month-to-month contracts show higher churn
- Long-term contracts reduce churn significantly
- Higher monthly charges are linked with increased churn
- Certain payment methods show higher churn behavior
